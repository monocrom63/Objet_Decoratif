The menu name must read “OBJET DÉCORATIF” in uppercase and explicitly use Chakra Petch, matching “Objects With a Glow”.

**Why:** The owner repeated the same-font requirement because the original small wordmark still looked like the old font, then explicitly specified uppercase lettering and Chakra Petch by name.

**How to apply:** Keep the uppercase wordmark large enough to show its angular lettering, rather than treating it like a small navigation label. Check the visible result on desktop and mobile, not just its CSS font-family declaration.
